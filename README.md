# AutoFill Extension

Automatically fill web forms with random or manual data.

## Features

✅ **Random Fill** - Fills forms with random names, emails, phone numbers, addresses
✅ **Manual Fill** - Fill with your own saved data
✅ **Smart Detection** - Automatically detects form field types
✅ **One-Click** - Simple popup interface
✅ **Works on All Sites** - Compatible with most websites

## Installation

### Firefox
1. Go to `about:debugging#/runtime/this-firefox`
2. Click "Load Temporary Add-on"
3. Select the folder containing this extension

### Chrome
1. Go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the folder containing this extension

## How to Use

1. Click the extension icon
2. Choose:
   - **🔄 Random Fill** - Auto-fill with random data
   - **✏️ Manual Fill** - Auto-fill with saved data
   - **⚙️ Settings** - Save your personal data

## Files

- `manifest.json` - Extension configuration
- `popup.html` - Extension UI
- `popup.js` - Popup functionality
- `popup.css` - Styling
- `content.js` - Form filling logic
- `background.js` - Background service worker
